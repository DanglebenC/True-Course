TrueCourse

Stellic Pathfinders Challenge · Degree Planning & Discovery

A Chrome extension that reads a student's real Degree Works audit and recommends next semester's courses like an advisor would — respecting prerequisites, flagging bottlenecks, and citing exactly what it verified versus inferred.

For judges: install & test Watch the 2-minute demo View source on GitHub

The problem

Only 55% of college students say they've actually been advised on the specific coursework required for their degree. It's not that advisors don't care — it's that one person is asked to hold hundreds of individual degree plans in their head, with a fifteen-minute appointment as the only way in. When that system strains, students pay for it: courses that don't count, and graduation dates that quietly slip.

How it works

1

Scan

Reads the currently open Degree Works audit directly out of the page — completed, in-progress, and still-needed courses, grouped by requirement block.

2

Look up

Automatically pulls real prerequisites and section/meeting times for every needed course — no clicking through Degree Works course by course.

3

Ask

Asks the student's target graduation term, course load, time-of-day preference, and whether to stick to the minimum or explore extra electives.

4

Advise

Claude reasons over the verified audit like a real advisor — prioritizing bottleneck courses, catching grade/prerequisite mismatches, and separating fact from inference.

Built like a real advisor would think

Verified prerequisites & sections

Looks up real prerequisite and section/CRN data straight from Degree Works for every course still needed — automatically, with no manual steps.

Minimum-grade cross-check

Degree Works marks a prerequisite "complete" the moment it's passed, regardless of grade. TrueCourse checks the actual grade against what the next course requires.

Term-availability awareness

Flags courses with a restrictive offering pattern (e.g. Fall-only) that are worth locking in early, even if they're not part of the immediate plan.

Full-time credit check

Warns if a recommended plan would drop the student below the standard 12-credit full-time threshold.

Questions for your advisor

Closes every plan with a short list of anything inferred rather than verified — turning it into an actual question to bring to a real advisor.

Works off the page you're already in

No new login, no separate app, no integration a school has to build first. Reads the same audit data a real advisor would see.

For judges: installing and testing

TrueCourse is a Chrome extension, not a hosted web app, so there's nothing else to click into from here except the source. It isn't published to the Chrome Web Store — this is a hackathon-scale build pointed at a sensitive, login-gated page.

  1. Download or clone the GitHub repository.
  2. In Chrome, go to chrome://extensions.
  3. Turn on Developer mode (top right toggle).
  4. Click Load unpacked and select the truecourse-extension folder.
  5. Click the extension icon, then "Open Sample Degree Works Page" to test without needing a real login — a bundled mock audit exercises the full scan → lookup → recommendation pipeline.

A Claude API key is required to generate a live recommendation (Options → paste a key from console.anthropic.com). For this review period, a working key is being shared with judges directly through the submission process rather than committed to the public repo. The per-student key requirement is still a known, documented limitation of this prototype — see the README for the plan to route it through a school-hosted backend at scale.
